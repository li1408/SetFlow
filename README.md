# SetFlow

SetFlow 是一款面向个人与少量朋友使用的 Android 本地健身辅助应用。它把训练执行压缩成一条清晰路径：打开今日计划、完成一组、自动休息提醒、继续下一组。

规格已确认，当前正在按测试驱动的增量计划实现。主验收设备为小米 15；实际 HyperOS/Android 版本将在真机连接后读取。
